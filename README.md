# 📦 E-Commerce Sales Analysis & Customer Segmentation

## End-to-End Data Analytics Project using Python & Power BI

---

## 📌 Project Overview

This project demonstrates a complete data analytics workflow using a real-world retail dataset. The objective was to transform raw transactional data into actionable business insights through data cleaning, exploratory analysis, customer segmentation, and interactive dashboard development.

The project combines Python for data processing and Power BI for business intelligence reporting.

### Key Outcomes

* Cleaned and transformed 500,000+ retail transactions
* Performed customer behavior analysis using RFM segmentation
* Identified high-value and at-risk customer groups
* Built an interactive Power BI dashboard for business decision-making
* Generated insights to support customer retention and revenue growth strategies

---

## 🎯 Business Objective

Retail companies often possess large amounts of customer transaction data but lack visibility into:

* Which customers generate the highest value
* Which customers are likely to stop purchasing
* Which products drive the majority of revenue
* How purchasing behavior changes over time

This project addresses these challenges through customer analytics and data-driven segmentation techniques.

---

## 📂 Dataset

**Dataset:** Online Retail Dataset (UCI Machine Learning Repository)

The dataset contains historical transactions from a UK-based online retailer.

### Features

| Column      | Description               |
| ----------- | ------------------------- |
| InvoiceNo   | Unique invoice number     |
| StockCode   | Product identifier        |
| Description | Product description       |
| Quantity    | Number of items purchased |
| InvoiceDate | Transaction timestamp     |
| UnitPrice   | Product price             |
| CustomerID  | Customer identifier       |
| Country     | Customer country          |

## 🧹 Data Cleaning

To ensure reliable analysis, the following preprocessing steps were performed:

* Removed missing Customer IDs
* Eliminated duplicate records
* Filtered cancelled and invalid transactions
* Removed negative quantities and prices
* Converted date columns into proper datetime format
* Validated transactional consistency

## 👥 Customer Segmentation (RFM Analysis)

Customers were segmented using the RFM framework.

### Recency (R)

Days since the customer's most recent purchase.

### Frequency (F)

Number of purchases made by the customer.

### Monetary (M)

Total revenue generated by the customer.

---

### Customer Segments

| Segment            | Description                                     |
| ------------------ | ----------------------------------------------- |
| 👑 Champions       | High-value and highly engaged customers         |
| ❤️ Loyal Customers | Frequent repeat customers                       |
| 🟢 New Customers   | Recently acquired customers                     |
| ⚠️ At Risk         | Previously valuable customers becoming inactive |

## 🔍 Key Findings

### Customer Concentration

A relatively small percentage of customers generates the majority of overall revenue, confirming the Pareto Principle (80/20 rule).

### Revenue Drivers

Champions and Loyal Customers contribute the largest share of business revenue.

### Retention Opportunities

At-Risk customers represent a significant opportunity for retention campaigns.

### Product Demand

Revenue is highly concentrated among a limited number of products.

### Behavioral Trends

Customer purchasing behavior exhibits strong seasonal and time-based patterns.
